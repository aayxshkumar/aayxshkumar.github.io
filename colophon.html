Colophon

Type

Set in Charter, which Matthew Carter drew in 1987, at 19 px on a measure of 62 characters; 17 px on phones. Nothing is downloaded. macOS and iOS ship Charter. Windows shows Sitka Text, also by Carter; Android shows Noto Serif. font-size-adjust matches each fallback’s x-height to Charter’s, so the line lengths hold. Code is in your system’s monospace, scaled to the same x-height as the text.

Colour

Colour appears only in data. Blue is v2 and bids; red is v0 and asks, at matched lightness, so neither looks more important. There is no green: in some markets red means rising, and red against green is the commonest colour-blind confusion. The ink isn’t black. It is the bid blue at 22% lightness, oklch(22% .012 255), and the greys share its hue. Links are a separate blue and stay underlined. Dark mode follows your system.

The margin

From 1,152 px wide, every table and figure has its method beside it in the right margin: machine, compiler, statistic, commit, data file and script. On a narrower screen the same text is the caption. Each post ends with a dated list of revisions. Pages print to A4 with page numbers and link addresses, and the write-up is also a PDF.

Numbers

Every headline number on the site is listed in receipts.json, with what backs it, and the claims ledger is generated from that file by build.py. build.py --check fails if a page still carries a number this site has corrected.

How it’s built

A handful of HTML files, one stylesheet and two small scripts, served by GitHub Pages. No framework, no web fonts, no analytics, no cookies, and no requests to anyone else’s server. The charts are SVGs written by short Python scripts, from lob-engine’s committed CSV or from figures copied out of its committed benchmark output. The step-through on the home page ports lob-engine’s matching rules to JavaScript, and does nothing until you click; without JavaScript, the table above it says the same thing.

Pages prefetch on hover and cross-fade in Chrome and Safari; other browsers load them normally. Nothing animates if your system asks for reduced motion.

The home page is 19.6 KB of HTML, CSS and JavaScript, compressed, plus 1.1 KB for its chart and icon. It loads no fonts.

AI

Much of the code in lob-engine and on this site was written with Claude Code, Anthropic’s AI coding assistant, working from my direction. So far that is every commit in both repositories, and each one says so in a Co-Authored-By: Claude trailer. The numbers come from runs on my own machine, and the claims ledger shows which of them you can check yourself.
