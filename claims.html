Claims ledger

Every headline number on this site, where it comes from, and what you can check today. A row says “public at” a commit only when a stranger can check the number against something in lob-engine at that commit. Anything still missing says so in red.

Every benchmark ran on an Apple M4, macOS 26, Apple clang 17, -O3, one thread; each figure is the median of 10 interleaved repetitions (for the replay, of 5 runs). The machine was not idle: each of the four runs from 29–30 October started with a load average of 2.4 to 3.8, and where other processes were sampled, Spotlight indexing held about one core. Ratios between versions are stable (v0 agrees within 1% across branches, and main’s two runs within 2%); absolute figures may be a few percent low.

Run it

These are the flags tools/run_bench.sh passes. It runs every benchmark this way, with no filter, and keeps the output under bench/results/; that is how the committed runs were made.

v0 and v2, the mixed workload, at 5cbfc0c

git checkout 5cbfc0c
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
./build/lob_bench \
  --benchmark_filter='^(v0_map|v2)/mixed/1000000/262144$' \
  --benchmark_repetitions=10 --benchmark_enable_random_interleaving=true

v1, the mixed workload, at 56199b6 on branch v1-random (v1 is no longer in main’s tree)

git checkout 56199b6
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
./build/lob_bench \
  --benchmark_filter='^v1_array/mixed/1000000/262144$' \
  --benchmark_repetitions=10 --benchmark_enable_random_interleaving=true

The replay, which runs 5 repetitions itself; it needs your own recording

python3 tools/record_binance.py BTCUSDT 1200 data/btcusdt.lobrec
./build/lob_replay data/btcusdt.lobrec

What each status means

public at a commit
The raw data, or the code that produces the number, is in lob-engine at that commit.
raw output public at a commit
The run that produced the number is committed, with its output: bench.json from Google Benchmark, every repetition and the medians, or replay.txt for the replay, next to a meta.txt with the commit, compiler and load average. Main’s runs are at e12cc5d and v1’s on branch v1-random at 752c2cf. The figures these replaced, from runs whose output wasn’t kept, are listed in each row as the earlier figure.
README only
The README states it, and nothing committed reproduces it yet: the planted bugs aren’t committed as patches.
anyone with a Mac can check it
One command on your own machine settles it.
employer figure
The Airbus numbers. They come from my work there and can’t be published; nothing here pretends otherwise.
